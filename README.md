# Cinema API

Серверна частина кінотеатру: фільми, зали, розклад сеансів і бронювання місць. Побудована на NestJS, дані зберігаються в масивах усередині сервісів і зникають після перезапуску процесу.

## Встановлення

Потрібен Node.js 22.12 або новіший.

```bash
npm install
```

## Змінні середовища

Створіть файл `.env` у корені проєкту, наприклад скопіюйте зразок командою `cp .env.example .env`:

```dotenv
PORT=3000
```

| Змінна | Опис                         | Типове значення |
| ------ | ---------------------------- | --------------- |
| `PORT` | Порт, на якому слухає сервер | `3000`          |

## Запуск у режимі розробки

```bash
npm run start:dev
```

Swagger доступний на [http://localhost:3000/docs](http://localhost:3000/docs).

## Перевірка роботи

Файл [requests.http](requests.http) містить запит до кожного маршруту і на кожну описану помилку. Відкрийте його у VS Code з розширенням REST Client і виконуйте запити згори вниз: ідентифікатори підставляються зі змінних, очікуваний код відповіді вказаний у заголовку запиту.

Автоматичні тести:

```bash
npm run test:e2e
```

## Структура

```
src/
├── common/     спільні декоратори та pipe
├── films/      операції з фільмами
├── halls/      операції із залами, обчислення переліку місць
├── showings/   операції із сеансами, фільтрація розкладу
└── bookings/   бронювання та зайнятість місць на сеансі
```

Залежності між модулями йдуть в один бік: `bookings → showings → films, halls`.

- Перед видаленням фільму чи залу треба знати, чи є на нього сеанси. Щоб `films` і `halls` не залежали від `showings` у відповідь, `ShowingsService` під час старту реєструє в їхніх сервісах функцію перевірки через `registerUsageCheck`.
- Маршрути `/showings/:id/bookings` і `/showings/:id/seats` живуть у модулі `bookings`, бо для відповіді потрібні дані про бронювання.

## Домовленості

- `startsAt` зберігається й повертається в UTC, тому `2030-06-15T18:00:00+03:00` у відповіді стане `2030-06-15T15:00:00.000Z`. Фільтр `date` теж рахує добу за UTC.
- Неправильно сформований `:id` дає 404, як і неіснуючий, бо запису з таким id немає.
- Поля, яких немає в DTO, мовчки відкидаються, запит через них не падає.
- Зал обмежений 1000 рядами і 1000 місцями в ряду, а ціна квитка 100 000 000 копійок. Рік випуску фільму не може бути раніше за 1888.
